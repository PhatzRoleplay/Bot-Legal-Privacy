What We Built

The bot began as a Node.js project on a Windows development PC. GitHub stores the source code, while an Oracle Cloud Ubuntu server runs the live production bot 24/7.

In simple terms

The Windows PC is where the bot is developed. GitHub is the private source-code repository. Oracle Cloud is the computer that actually keeps the bot running. Discord is where the bot operates.

Important: Your PC does not need to stay on for the bot to remain online.

24/7 Bot Service

Ubuntu uses systemd to keep the bot running automatically.

Service name

The service automatically starts when the server boots and restarts the bot if the Node.js process crashes.

Server Commands

Commands used when administering the live bot.

Check bot status

sudo systemctl status phatzrp-bot --no-pager

Start bot

sudo systemctl start phatzrp-bot

Stop bot

sudo systemctl stop phatzrp-bot

Restart bot

sudo systemctl restart phatzrp-bot

Updating the Bot

The recommended workflow is to develop locally, push to GitHub, then deploy the changes to Oracle.

1. Make changes locally

Edit the bot on the Windows development PC.

2. Push the changes to GitHub

Use GitHub Desktop or Git to commit and push the updated code.

3. Pull the changes onto Oracle

cd ~/phatzrp-discord-bot
git pull

4. Update dependencies when required

npm install

5. Restart the production bot

sudo systemctl restart phatzrp-bot

Logs & Troubleshooting

Use these commands when something isn't behaving correctly.

View recent logs

sudo journalctl -u phatzrp-bot -n 50 --no-pager

Watch live logs

sudo journalctl -u phatzrp-bot -f

Press Ctrl + C to stop watching the live output.

If the bot is offline: Check the service status first, then inspect the recent journal logs for Node.js or configuration errors.

Security

The following credentials and secrets should never be committed to the public documentation repository or the private source repository.

Discord Bot Token .env SSH Private Keys Database Passwords API Keys

Environment files

The production .env exists only on the Oracle server. The local development copy exists on the PC. Neither is stored in GitHub.

Never use cat .env or paste the contents of your production environment into a public chat or repository.

Future Development

The current hosting architecture is independent from the future functionality of the bot.

Qbox Integration FiveM Integration FiveGuard Database Warning History Ban History Player History Ticket System

The important part

These features can be added later without rebuilding the hosting environment. The GitHub repository remains the source of truth, while Oracle Cloud remains the live production environment.
