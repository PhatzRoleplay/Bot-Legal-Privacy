Privacy Policy

Effective Date: August 24, 2026

1. Information We Collect

To deliver automated FiveM role integration, player moderation, and server management features, the Bot processes and stores specific data elements:

  • Discord Identifiers: Discord User ID, account handle, server nick, and role assignments.
  • Game Identifiers: Steam Hex ID, License ID, Live ID, or FiveM player identifiers explicitly linked to your Discord ID.
  • Audit Logs: Command interaction timestamps, warning/ban history, and whitelist application states.

2. Purpose of Data Processing

Collected data is strictly utilized for core gaming server functionality, including syncing Discord permissions with in-game job/whitelist ranks, processing player moderation logs, and maintaining anti-cheat/whitelist security.

3. Data Security & Third Parties

All stored records are retained on private, password-protected databases managed by PhatzRP team. We do not sell, rent, trade, or transfer your data to external services, advertisers, or third parties.

4. Data Retention & Erasure Requests

Data is stored only for the duration of your membership in the community. If you depart the server and wish to request full deletion of your linked player profile data, please open a support ticket in the official PhatzRP FiveM Discord server https://discord.gg/phatzrp.
